# FirmaA
Разработка на технологично отделение в компания

## Frontend

Vue 3 + Vite + [Nuxt UI](https://ui.nuxt.com) in `frontend/`.

- Local dev: `cd frontend && npm install && npm run dev` → http://localhost:3000
- Every push to `main` that touches `frontend/` deploys to GitHub Pages via
  `.github/workflows/deploy-pages.yml` → https://idraykova22.github.io/FirmaA/
